# DMIT 日本評測：東京 CN2 GIA 與 T1 全套餐解析，看懂線路差異、延遲表現與該挑哪一款

會去查 DMIT 日本評測的人，動機通常很單純：手上需要一個日本 IP，但不希望大陸用戶連上去卡成幻燈片。東京到華東的物理距離就在那裡，走優化線路能把延遲壓在比香港高一點、比洛杉磯低一大截的位置，這個區間沒有太多替代品。

問題是，你查到的資料很可能已經過期。DMIT 東京機房在過去一年動過產品線，原本三條路線現在只剩兩條，而且退場的那條，恰好是很多舊評測評最兇的那條。

先把最關鍵的變化講清楚，再來談線路、實測數據和該不該買。

## 東京機房現在賣什麼：三條線縮成兩條

DMIT 東京（機房代號 TYO）目前官網上還在賣的，只有這兩個系列：

- **TYO.AS3.Pro（Premium）**：回程走中國電信 CTG GIA（也就是俗稱的 CN2 GIA），聯通走 AS9929／10099 精品線，移動走 CMI，去程也做過優化。這是東京最貴、線路最好的一檔。
- **TYO.AS3.T1（Tier 1）**：純國際互聯，完全沒有針對大陸方向做優化。價格最低，超量之後降速不停機。

**已經下架的是 Eyeball（TYO.AS3.EB）。** 它原本的路由是三網回程 CMIN2、電信與聯通去程跑 CTG GIA、移動去程走 CMI，在一票評測裡被當成「移動用戶的性價比解」。現在官網日本區已經找不到這個系列，而且持有該機型的用戶收到過官方通知：TYO EB 系列將於 2026 年 6 月 15 日正式下線，6 月 22 日前還可透過工單緊急取回資料，之後資料永久刪除。

這件事對正在查評測的人影響很直接：**任何推薦你買 TYO AS3.EB 的文章，都不要再照著點了。** 你只會買到缺貨，或者更糟——在二手市場接手一個即將到期的機器。

硬體方面三個系列曾經共用同一個平台：Equinix TY8 機房、KVM 虛擬化、AMD EPYC 7003（Milan）系列處理器、SSD 儲存，標配 1 個 IPv4 加 1 個 IPv6 /64。付費方式支援支付寶、PayPal 和信用卡，對中文用戶算友善。

## TYO.Pro 實測表現：延遲是它的全部理由

Pro 系列的核心賣點只有一個——回程走 CTG GIA。這條線的意義在於避開晚高峰的公共交換節點，代價是價格。

第三方評測裡比較常被引用的數據：

- **延遲**：多家測評對東京 Pro 機型的記錄落在 60ms 上下，上海節點最低測到過 31ms 左右。這個數字比香港機房略高，但比洛杉磯動輒 150ms 以上好得多。
- **硬體**：有評測在 TYO.AS3.Pro.TINY 上跑到 AMD EPYC 7443P 單核，Geekbench 5 單核 977、多核 954，Fio 順序讀取 340MB/s、寫入 1051MB/s。入門款本來就不是跑高負載的配置，這個成績屬於正常水位。
- **流媒體**：多篇測評提到 Netflix、YouTube Premium、Amazon Prime Video 可以解鎖，IP 歸屬地顯示日本。

有兩點必須先講清楚，因為它們比延遲更容易讓人踩坑：

**第一，流量超額是停機，不是降速。** Pro 系列跑完當月流量，服務直接暫停，要等下個計費週期恢復。500GB 對一般部落格或個人使用夠用，但如果你拿它做中轉、跑大量下載，這個設計會讓你在月中就斷線。

**第二，Pro 系列常缺貨。** 東京 Pro 的庫存不是隨時都有，補貨往往只是因為釋放出一批可用 IP，賣完就沒了。想買的話，事先加入監控或關注補貨通知會比臨時去官網碰運氣實際。

## TYO.T1 實測表現：便宜，但別期待大陸速度

T1 是完全不同的定位。它的路由是純國際互聯：電信雙程走 NTT，聯通雙程走 NTT，部分方向會繞美國 Lumen，移動走 CMI。第三方測評記錄的全國平均延遲大約在 204ms，電信方向因為繞道，數字明顯偏高。

也就是說，**如果你的使用者在大陸，T1 不是拿來當入口的選擇。** 它適合的是另一批場景：日本落地節點、面向日本或東南亞使用者的服務、多地區架構裡的中繼、單純要一個便宜日本 IP 的用途。

它真正的優勢在超量策略：

| 方案 | 超量後處理 |
| --- | --- |
| T1.WEE | 50Mbps 不限流量 |
| T1.TINY / STARTER / MINI | 100Mbps 不限流量 |
| T1.MICRO / MEDIUM | 200Mbps 不限流量 |
| T1.LARGE | 500Mbps 不限流量 |

流量用完不會斷線，只是被限速。對於流量波動大、不能接受停機的用途，這個設計比 Pro 更實用。另外記憶體 4GB 以上的方案支援安裝 Windows，這在低價日本 VPS 裡不算普遍。

測試 IP：Pro 系列可測 154.12.190.32，T1 系列可測 154.31.112.5。下單前自己 ping 一輪，比看任何評測都準。

## 該買哪一款：三種情況直接對號入座

看完數據，判斷其實不複雜。

**買 Pro，如果你的使用者主要在大陸。** 建站、API 服務、遊戲加速、跨境業務，這些場景對晚高峰的丟包率很敏感，CTG GIA 回程帶來的差異是可以直接感覺到的。預算有限就從 Pro.TINY 開始，$21.90 的入門價在這個線路等級裡不算離譜。

**買 T1，如果你要的只是日本 IP 和穩定硬體。** 面向日本或國際使用者的網站、多地區架構的中繼節點、流量波動大又不想半夜被停機的用途，T1 的性價比明顯更高，WEE 年付 $36.90 的門檻也很低。

**兩種都別買，如果你的使用者全在歐美。** 那你買東京只是在替延遲付溢價，選美西機房更合理，這個判斷跟品牌無關。

還有一種情況值得單獨說：**如果你的需求是「移動用戶體驗優先」**，那原本該選的是已經下架的 EB 系列。現在東京只剩 Pro 和 T1，移動方向要嘛接受 Pro（走 CMI 出口），要嘛去看其他機房，不要再去追 EB 的舊推薦。

## 優惠、下單與幾個容易踩的坑

DMIT 的促銷節奏跟某些商家不一樣，很少出現全場半價這種活動，折扣碼數量少、綁定條件也多。實際觀察到的規律是這樣：

- 折扣碼通常**綁定產品線和付款週期**。東京 Pro 的循環折扣多半要求季付以上，月付基本吃不到；T1 系列偶爾有更深的折扣。
- 針對**老客戶加購**有一個約 10% 的折扣機制，條件是帳戶內已有成功訂單，且累計月均消費達到一定門檻（T1 系列通常不受此限制）。
- 論壇和整理站流傳的優惠碼大量已經過期。**結帳前在購物車頁面試一次，看金額有沒有真的變動**，比相信任何清單都可靠。

下單流程本身沒什麼難度：註冊帳號、選東京機房與方案、在結帳頁輸入折扣碼確認最終價格、用支付寶或 PayPal 付款，通常幾分鐘內自動開通。有兩件事新手常卡住：

1. **註冊時別掛代理，資料照實填。** 系統對異常 IP 和明顯偽造的資訊有風控，觸發後可能直接退款。
2. **預設走 SSH 金鑰登入，不寄密碼。** 第一次連接前要先把公鑰上傳到控制台，沒做這步會一直連不上。

政策方面，第三方整理常提到 IP 被牆時每 15 天可免費更換一次，其他情況的更換需要間隔 30 天並可能產生費用。這類條款會調整，實際以官網政策頁面與客服回覆為準。

## 結論

DMIT 東京的價值集中在 Pro 那條 CTG GIA 回程上。它是目前少數能同時給你日本原生 IP 和穩定大陸回程的選擇，代價是流量超額直接停機、價格不低、而且經常缺貨。

T1 則是另一個物種——國際線路，別指望大陸速度，但用同樣的錢能拿到數倍的硬體與流量，超量降速也比停機友善。先想清楚你的使用者在哪裡，再決定要為哪一種價值付錢，比比較哪家評測分數高更有意義。

至於已經下架的 Eyeball，就讓它留在 2025 年的文章裡吧。
